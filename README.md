# 🧑‍🏫 Sistema de Cadastro de Alunos com Boletim

> Um sistema CLI desenvolvido em Python aplicando conceitos fundamentais de Programação Orientada a Objetos (POO) e persistência de dados em JSON.

---

## ✨ Funcionalidades

- [x] **Gestão de Alunos:** Cadastro completo (nome, idade e matrícula) e remoção.
- [x] **Boletim & Notas:** Adição de múltiplas notas por aluno, cálculo automático de média e status de aprovação.
- [x] **Busca Rápida:** Localização de alunos por nome ou número de matrícula.
- [x] **Persistência de Dados:** Salvamento e carregamento automático das informações em arquivos `.json`.
- [x] **Navegação Amigável:** Interface de linha de comando (CLI) simples e interativa.

---

## 🛠️ Tecnologias & Conceitos Aplicados

* **Linguagem:** Python 3
* **Paradigma:** Programação Orientada a Objetos (Herança, Encapsulamento, Abstração e Polimorfismo)
* **Armazenamento:** Módulo `json` para manipulação e persistência local de dados
